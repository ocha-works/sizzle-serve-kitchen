Sizzle & Serve is an original top-down cooking game: run the Hearthside Kitchen through a 3-minute lunch shift. Take ingredients from the pantry, chop them on the board, cook them on the stove, build each dish on the plating counter, and serve it at the window before the order's patience runs out. Five original recipes combine in different ways, rush levels speed up the orders, and fast serves build a combo multiplier.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys (or click a spot to walk there), press E to work the nearest station, Q to toss the last carried item, P to pause, M to mute, and R to start a new shift. The game is plain static files under game/ and runs fully offline.
